# 💰 Sina Finance — Personal Finance Manager

A professional, modern, and privacy-focused personal finance management application built to help users track, analyze, and manage their financial life with ease.

### ✨ Key Features

- 📊 Professional financial dashboard
- 💰 Income & expense tracking
- 💳 Multiple accounts, wallets & cards
- 🔄 Transfers between accounts
- 📈 Advanced financial analytics & interactive charts
- 🗂️ Smart categories & custom categories
- 🎯 Budget management & spending limits
- 🔁 Recurring transactions
- 💸 Debt & receivable management
- 📅 Installments & payment reminders
- 📆 Financial calendar
- 🔎 Advanced transaction search & filtering
- 📩 Optional bank SMS transaction detection
- 🔐 Secure PIN & biometric app lock
- ☁️ Google Sign-In & Google Drive backup
- ♻️ Backup & restore after reinstalling the app
- 📄 Professional PDF reports
- 📊 Excel (.xlsx) financial exports
- 🌙 Dark & Light Mode
- 🇮🇷 Iran / 🇺🇸 USA support
- 💵 Toman / USD automatic currency configuration
- 🌐 Persian & English localization
- 🔢 Automatic number, date & currency formatting
- 📱 Responsive RTL / LTR interface
- ⚡ Offline-first architecture
- 🛡️ Privacy-focused data handling
- 🚀 Smooth animations & premium fintech UI

### 🔒 Privacy First

Bank SMS detection is completely optional and requires explicit user permission. Sensitive SMS such as OTP and verification messages are not treated as financial transactions. Core financial features remain available without SMS access or cloud connectivity.

### ☁️ Backup & Recovery

With Google Sign-In and Google Drive backup, users can securely back up their financial data and restore it after reinstalling the application.

### 📤 Professional Reports

Generate detailed financial reports in:

- Excel
- PDF

with customizable date ranges, accounts, categories, transactions, summaries, and analytics.

### 🇮🇷 Iran & 🇺🇸 USA

Sina Finance is initially designed for two markets:

**Persian → Iranian Toman (تومان)**\
**English → US Dollar ($)**

Language, currency, RTL/LTR layout, numbers, and date formatting automatically adapt to the selected environment.
